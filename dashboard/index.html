Data path

What happens each tick?

  1. 1
    Software telemetry

    A deterministic plant produces current, voltage, SOC and surface temperature.

  2. 2
    Checkpoint inference

    The backend evaluates the trained PC-MP-PINN at 25 radial coordinates.

  3. 3
    Physics coupling

    Concentration is converted into radial and tangential particle stress.

  4. 4
    Forecast and persistence

    The system predicts short horizons, evaluates thresholds and stores the tick in SQLite.

Scientific honesty

What this demonstration proves

  • Real backend checkpoint execution
  • Continuous WebSocket updates
  • Hidden-state estimation with physical coupling
  • Repeatable software fault scenarios
  • Persistent, exportable experiment sessions

What it does not claim

  • No hardware measurements are connected.
  • No certified battery-safety decision is produced.
  • No 3D cell hotspot is inferred from a lumped thermal model.
